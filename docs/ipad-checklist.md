# iPad実機チェックリスト

端末、iPadOS、Safariの版、確認日を記録してください。デスクトップのWebKit確認を実機確認済みとして扱いません。

## 起動と保存

- [ ] Safariで公開URLを開ける
- [ ] 「ホーム画面に追加」後、アイコンとアプリ名が正しい
- [ ] ホーム画面からアドレスバーのないスタンドアローン表示で起動する
- [ ] オンラインで一度利用後、機内モードでも主要画面と練習画面を再起動できる
- [ ] 公開版更新後、古いキャッシュに固定されず新しい版へ切り替わる
- [ ] Safari表示とホーム画面表示で保存共有の実態を確認した
- [ ] 再読み込み後、追加駅・完了位置・途中位置が残る
- [ ] ブラウザデータ削除後の説明が実態と合う

## 横向き 1024×768相当

- [ ] 鉄道会社→路線の順で選べ、解除済み路線の切替、表示切替、拡大・縮小、駅選択が押しやすい
- [ ] 未解除の東京メトロに鍵と「あと何路線」が表示され、選択できない
- [ ] 長い路線を横スクロールでき、「せんとうへ もどる」「ぜんたいを みる」が使える
- [ ] 五十音表の文字ボタンと検索結果カードが欠けず、押しやすい
- [ ] 筆記面を約400px四方確保できる
- [ ] 左利き設定で操作群が右側にあり、手で隠れにくい
- [ ] Apple Pencilと指で線が飛ばない
- [ ] 筆記中にページがスクロールしない
- [ ] 筆記中に画面のラバーバンドや拡大・縮小が起きない
- [ ] 指が筆記面の外へ少し出ても線が途切れない
- [ ] 複数の指が触れても2本目を筆跡として扱わない
- [ ] 筆記面の外では必要なスクロールができる
- [ ] 描画を中断したあとも筆記面の外をスクロールできる

## 縦向き 768×1024相当

- [ ] 主要ボタンと筆記面が画面外へ欠けない
- [ ] 路線図の横スクロールとページ縦スクロールを使い分けられる
- [ ] 鉄道会社と路線の選択欄を横スクロールでき、現在の会社・路線が分かる
- [ ] 五十音表を縦スクロールでき、未使用文字が薄い押せない表示になる
- [ ] 回転後も既存の線と入力位置がずれない

## 音声

- [ ] 最初のタップ後に日本語音声が出る
- [ ] 自由が丘を「じゆうがおか」と読む
- [ ] 御嶽山を「おんたけさん」と読む
- [ ] 一文字と駅名全体を別々に聞ける
- [ ] 文字列を高速になぞっても音声が待ち行列にならない
- [ ] ミュート、音量、速度が反映される
- [ ] 音声が利用できなくても練習を続けられる

## 練習と演出

- [ ] 画順番号、始点、アニメーションが読み取れる
- [ ] 濁点、小書き文字、同じ文字の複数位置を別々に練習できる
- [ ] 点を置いただけでは「できた」が有効にならない
- [ ] 一文字で駅が追加される
- [ ] 全位置の練習後だけ星印が付く
- [ ] 隣接駅だけが線でつながり、電車が走る
- [ ] 路線の最終駅を完了すると全線のお祝いが一度表示され、路線タブにメダルが残る
- [ ] 「おいわいを みる」から全線のお祝いを再生できる
- [ ] 全駅をお手本なしで完了すると「ろせんマスター」と★★が表示される
- [ ] 共有駅で複数路線が同時に完成した場合、各路線のお祝いを順に見られる
- [ ] 東急9路線・相鉄3路線の通常クリア後に東京メトロが解除され、再起動後も解除されたままになる
- [ ] 東京メトロ解除直後は銀座線・半蔵門線を選べ、ほか7路線は選択式の鍵表示になる
- [ ] 練習文字位置が25・50・75・100%に達すると区間スタンプが増え、2個、その後3個ごとに好きな路線を1本解除できる
- [ ] 段階解除導入前に東京メトロ解除済みのバックアップでは9路線すべてを引き続き選べる
- [ ] 「動きを減らす」と端末設定で演出が止まるか短くなる

## 親画面

- [ ] 長押しで入り、短い誤タップでは入らない
- [ ] 未対応文字を含む駅を追加して自由書きできる

- [ ] JSON書き出しと復元でデータが戻る
