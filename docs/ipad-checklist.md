# iPad実機チェックリスト

端末、iPadOS、Safariの版、確認日を記録してください。デスクトップのWebKit確認を実機確認済みとして扱いません。

## 起動と保存

- [ ] Safariで公開URLを開ける
- [ ] 「ホーム画面に追加」後、アイコンとアプリ名が正しい
- [ ] Safari表示とホーム画面表示で保存共有の実態を確認した
- [ ] 再読み込み後、追加駅・完了位置・途中位置が残る
- [ ] ブラウザデータ削除後の説明が実態と合う

## 横向き 1024×768相当

- [ ] 路線切替、表示切替、拡大・縮小、駅選択が押しやすい
- [ ] 筆記面を約400px四方確保できる
- [ ] 左利き設定で操作群が右側にあり、手で隠れにくい
- [ ] Apple Pencilと指で線が飛ばない
- [ ] 筆記中にページがスクロールしない
- [ ] 筆記面の外では必要なスクロールができる

## 縦向き 768×1024相当

- [ ] 主要ボタンと筆記面が画面外へ欠けない
- [ ] 路線図の横スクロールとページ縦スクロールを使い分けられる
- [ ] 回転後も既存の線と入力位置がずれない

## 音声

- [ ] 最初のタップ後に日本語音声が出る
- [ ] 自由が丘を「じゆうがおか」と読む
- [ ] 御嶽山を「おんたけさん」と読む
- [ ] 一文字と駅名全体を別々に聞ける
- [ ] 文字列を高速になぞっても音声が待ち行列にならない
- [ ] ミュート、音量、速度が反映される
- [ ] 音声が利用できなくても練習を続けられる

## 練習と演出

- [ ] 画順番号、始点、アニメーションが読み取れる
- [ ] 濁点、小書き文字、同じ文字の複数位置を別々に練習できる
- [ ] 点を置いただけでは「できた」が有効にならない
- [ ] 一文字で駅が追加される
- [ ] 全位置の練習後だけ星印が付く
- [ ] 隣接駅だけが線でつながり、電車が走る
- [ ] 「動きを減らす」と端末設定で演出が止まるか短くなる

## 親画面

- [ ] 長押しで入り、短い誤タップでは入らない
- [ ] 未対応文字を含む駅を追加して自由書きできる
- [ ] 既存路線の指定位置へ駅を挿入できる
- [ ] JSON書き出しと復元でデータが戻る
- [ ] 不正JSONと未知のschemaVersionで既存データが変わらない
- [ ] 全消去の確認をキャンセルできる
